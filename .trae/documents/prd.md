## 1. 产品概述

LinguaFlow 是一个沉浸式多语言在线学习平台，支持英语、日语、韩语等主流语言学习。平台通过分级课程体系、互动学习模块、个性化学习路径和社区激励机制，为用户提供高效、有趣的语言学习体验。

- **目标用户**: 语言学习者（学生、职场人士、语言爱好者）
- **核心价值**: 沉浸式学习体验、科学分级体系、智能个性化推荐、社区互动激励

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱/用户名注册 | 浏览课程、学习模块、查看进度、社区互动 |
| VIP用户 | 付费升级 | 解锁高级课程、专属学习路径、优先客服 |

### 2.2 功能模块

1. **首页**: 语言选择、课程推荐、学习进度概览、社区动态
2. **课程中心**: 分级课程列表、课程详情、课程筛选
3. **学习模块**: 词汇记忆、语法练习、口语跟读、听力训练
4. **个人中心**: 学习进度、成就徽章、学习统计、设置
5. **社区广场**: 学习动态、排行榜、话题讨论

## 3. 核心流程

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 渐变紫蓝色 (#6366F1 → #8B5CF6) 代表智慧与成长，搭配活力橙色 (#F97316) 作为强调色
- **辅助色**: 柔和的薄荷绿 (#10B981) 表示成功/完成，珊瑚红 (#EF4444) 表示错误/警告
- **按钮风格**: 圆角胶囊按钮，带微妙阴影和悬停动效
- **字体**: 标题使用 Space Grotesk（现代几何感），正文使用 DM Sans（清晰易读）
- **布局风格**: 卡片式布局，圆角设计，毛玻璃效果，流畅过渡动画
- **图标风格**: 线性图标，统一粗细，配合渐变填充效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | Hero区域 | 渐变背景、动态粒子效果、大标题、CTA按钮、语言选择器 |
| 首页 | 课程推荐 | 横向滚动卡片、课程封面、等级标签、进度条 |
| 首页 | 学习进度 | 圆环进度图、统计数据卡片、连续学习火焰图标 |
| 课程中心 | 筛选栏 | 下拉选择器、标签筛选、搜索框 |
| 课程中心 | 课程列表 | 网格布局卡片、悬停放大效果、等级徽章 |
| 学习模块 | 词汇记忆 | 翻转卡片动画、发音按钮、进度指示器 |
| 学习模块 | 口语跟读 | 音频波形可视化、录音按钮、评分仪表盘 |
| 个人中心 | 学习统计 | 折线图、柱状图、雷达图（词汇/语法/听力/口语） |
| 个人中心 | 成就系统 | 徽章网格、解锁动画、进度条 |
| 社区广场 | 排行榜 | 前三名特殊展示、用户头像、积分数字动画 |

### 4.3 响应式设计

- **桌面优先**: 针对 1440px 及以上屏幕优化，充分利用横向空间
- **平板适配**: 768px-1024px，调整网格布局为双列
- **移动端适配**: 375px-767px，单列布局，底部导航栏，触摸优化

### 4.4 动效设计

- **页面过渡**: 淡入淡出 + 轻微位移
- **卡片悬停**: 上浮阴影增强 + 微微放大
- **按钮交互**: 点击涟漪效果 + 颜色加深
- **进度更新**: 数字滚动动画 + 进度条填充动画
- **成就解锁**: 弹窗 + 徽章旋转放大 + 粒子庆祝效果
